GD vs Zombies — прототип мода Geode для Windows
Версия проекта: 0.1.0

ВАЖНО
Это проект с исходниками, а не готовый установочный .geode.
Игровая логика проверена отдельно. Windows DLL и пакет .geode здесь не
собирались; запуск интерфейса внутри Geometry Dash ещё нужно проверить.
Для получения .geode используй сборку ниже.

ЦЕЛЕВАЯ ВЕРСИЯ
Windows x64, Geometry Dash 2.2081, Geode 5.10.1.
SDK и bindings закреплены в настройках сборки. Другие версии GD не заявлены.
Если Geode показывает несовместимость, сначала проверь версии игры и загрузчика.

ЧТО ЕСТЬ
Мини-игра по механике Plants vs Zombies, запускаемая из главного меню GD:
- поле 5 x 9;
- 5 волн, суммарно 75 противников;
- 5 видов защитников;
- обычные, бронированные и быстрые враги;
- энергия, задержки покупки, стрельба, заморозка и взрывы;
- одна спасательная волна на каждой дорожке — аналог газонокосилки;
- лопата, пауза, перезапуск, победа и поражение;
- локальный счётчик побед в данных мода.

Графика персонажей — настоящие иконки Geometry Dash через SimplePlayer:
кубы, шары, кораблик и wave. Враги — перекрашенные вражеские кубы.
Поле и рамки рисуются кодом. Текстуры GD и материалы PvZ в архив не включены.
Это отдельный небольшой режим, без кампании, музыки и полного набора растений PvZ.

КАК ПОЛУЧИТЬ .GEODE БЕЗ УСТАНОВКИ КОМПИЛЯТОРА
1. Распакуй этот архив.
2. Создай пустой репозиторий на GitHub.
3. Загрузи СОДЕРЖИМОЕ папки gd-vs-zombies в корень репозитория.
   В корне должны оказаться mod.json, CMakeLists.txt, src, tests и .github.
   ZIP целиком загружать не нужно. Важно не пропустить папку .github!
4. На GitHub открой Actions → Build Windows mod → Run workflow.
   На ветке main/master сборка также запускается при загрузке файлов.
5. Дождись зелёного результата обоих заданий: Test game rules и Windows x64.
6. Внизу страницы этого запуска скачай artifact «gd-vs-zombies-windows».
7. Распакуй artifact. Внутри после успешной сборки будет файл .geode.

Этот проект содержит только настройку автоматической сборки.
Репозиторий не создавался, GitHub Actions ещё не запускались.
Если сборка падает, сохрани текст первой ошибки из шага Build Geode package.
Не переименовывай архив исходников в .geode — это не создаёт мод.

УСТАНОВКА ПОСЛЕ УСПЕШНОЙ СБОРКИ
1. Закрой Geometry Dash.
2. В Steam открой Geometry Dash → Управление → Просмотреть локальные файлы.
3. Скопируй полученный .geode в папку geode\mods рядом с игрой.
4. Запусти GD. Убедись, что мод включён в Geode.
5. Нажми кнопку «GD vs Z» справа вверху главного меню.

УПРАВЛЕНИЕ
Мышь: выбери карточку сверху, затем нажми пустую клетку.
1–5: выбрать защитника.
S или SHOVEL: лопата; затем нажми растение, которое хочешь удалить.
Пробел / Esc / PAUSE: пауза и продолжение.
RETRY: немедленно начать заново.
X в правом верхнем углу: вернуться в главное меню GD.
HELP: правила; после закрытия нажми RESUME.
Интерфейс на английском, чтобы работать со стандартным шрифтом GD.

ЗАЩИТНИКИ
1 CUBE  — 100 энергии. Стреляет по своей дорожке, 25 урона каждые 1,35 с.
2 ORB   —  50 энергии. Даёт 25 энергии каждые 9 с, первый доход через 6 с.
3 WALL  —  75 энергии. Стена с 950 HP.
4 FROST — 150 энергии. 20 урона каждые 2,1 с; замедляет врага на 3,5 с.
5 BOMB  — 125 энергии. Взрыв через 1 с, 500 урона по соседним клеткам
          своей дорожки и двух соседних. Радиус по горизонтали — 1,6 клетки.

Энергия собирается автоматически. Также приходит 25 энергии с неба раз
в 7 секунд, первая порция через 6 секунд. За уничтожение врага: +5.
Начальный запас: 275. Лопата не возвращает стоимость растения.
У каждой карточки своя перезарядка, общая для всех дорожек.

СОВЕТ
Сначала поставь несколько ORB в левый столбец, затем закрывай дорожки CUBE
по мере появления врагов. Добавь второй столбец CUBE, стены впереди и FROST.
Не ставь генераторы перед стрелками. Партия занимает примерно 4–5 минут.

ЛОКАЛЬНАЯ СБОРКА WINDOWS
Потребуются:
- Visual Studio 2022 с «Разработка классических приложений на C++»;
- CMake 3.21+ в PATH;
- Geode CLI;
- Geode SDK v5.10.1 и переменная GEODE_SDK, указывающая на его папку.

Официальная настройка инструментов:
https://docs.geode-sdk.org/getting-started/
https://github.com/geode-sdk/cli
https://github.com/geode-sdk/geode/releases/tag/v5.10.1

После настройки запусти build-windows.bat.
Либо выполни из корня проекта:
  cmake -S . -B build -G "Visual Studio 17 2022" -A x64
  cmake --build build --config Release

Готовый .geode ищи в build. Скрипт сам не меняет файлы игры.

ПРОВЕРКА ЛОГИКИ БЕЗ GD И GEODE
  cmake -S . -B build-tests -DGVZ_TESTS_ONLY=ON
  cmake --build build-tests --config Release
  ctest --test-dir build-tests -C Release --output-on-failure

Либо с GCC:
  g++ -std=c++23 -O2 -Wall -Wextra -Werror -Isrc tests/game_tests.cpp src/Game.cpp -o game_tests
  ./game_tests

Файлы:
  src/Game.*            — правила, волны и симуляция с фиксированным шагом 60 Гц;
  src/GardenLayer.*     — экран, кнопки, иконки GD и управление;
  src/main.cpp          — кнопка в главном меню через хук MenuLayer;
  tests/                — проверки правил и полного прохождения;
  .github/workflows/    — Windows-сборка на GitHub Actions;
  VALIDATION.txt        — что уже проверено и что ещё не проверялось.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ
- Нет сохранения текущей партии, только счётчик побед.
- Нет звуков боя, кампании, выбора уровней и мультиплеера.
- На другом Geode/GD может понадобиться адаптация API, а не только mod.json.
- Кнопка расположена справа вверху и может пересекаться с кнопками других модов.
- Совместимость с модами, меняющими SimplePlayer или меню, ещё не проверена.
- Прочность стен и экономика проверены ботом; баланс для живого игрока
  желательно оценить в игре.
